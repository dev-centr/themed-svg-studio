= Themed SVG Studio

A native D editor for semantic SVG tokens, presets, and explicit bindings.

== About

Themed SVG Studio edits version 1 themed-SVG manifests alongside source SVGs.
Its scope is semantic theme data: tokens, presets, palette overrides, and
explicit selector bindings. Geometry editing is intentionally out of scope.

The reusable D library contains the editor model, manifest types, diagnostics,
undo/redo, and an isolated JSON/JSONL subprocess boundary for
`@dev-centr/themed-svg`. Protocol version 1 reserves `inspect`, `validate`,
`transform`, `sanitize`, and `export`.

== Build

[source,powershell]
----
dub test -c unittest
dub build -c cli
dub build -c gui-headless
dub build -c gui # native Windows host
----

All product configurations select TGC. DUI is the application layer over Dew.
The registry dependency chain uses DUI 0.1.4, Dew 0.1.7, vello-d 0.1.4 where
the GPU configuration needs it, and TGC 0.1.1.

Install the versioned transformation companion before running previews or
exports:

[source,powershell]
----
npm install --global @dev-centr/themed-svg@0.2.1
----

== CLI

[source,powershell]
----
.\themed-svg-studio-cli.exe smoke
.\themed-svg-studio-cli.exe validate --svg diagram.svg --manifest diagram.theme.json
----

The external bridge command defaults to `themed-svg-stdio` from
`@dev-centr/themed-svg` 0.2.1. Use `--bridge` when testing another executable
path. The app also honors `THEMED_SVG_STDIO`; on Windows it checks the normal
per-user npm executable directory when the command is not already on `PATH`.

== Product surfaces

The GUI exposes token, preset, and binding inspectors; source, fixed, light,
dark, standalone-adaptive, and host previews; About, Help, redacted debug dump,
and honest update status. v0.1.0 does not claim automatic update application.
