Themed SVG Studio is a native D application for editing semantic tokens,
presets, palette overrides, and explicit SVG selector bindings. It delegates
structural SVG inspection and transformation to `@dev-centr/themed-svg`.

It does not edit paths, shapes, transforms, or other geometry.

Start with xref:tutorials/first-project.adoc[] or review
xref:explanation/architecture.adoc[] before embedding the library.
