Run the internal smoke path:

[source,powershell]
----
dub run -c cli -- smoke
----

Invoke one protocol operation:

[source,powershell]
----
dub run -c cli -- validate --svg diagram.svg --manifest diagram.theme.json
----

Use `inspect`, `validate`, `transform`, `sanitize`, or `export`. `--bridge`
selects the external executable. `--debug-dump` prints redacted build and
runtime context and does not include SVG contents or token values.
