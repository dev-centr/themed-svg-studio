. Build the software-only GUI with `dub build -c gui-headless`.
. Build the CLI with `dub build -c cli`.
. Keep an SVG and its version 1 manifest together.
. Run `themed-svg-studio-cli validate --svg diagram.svg --manifest
  diagram.theme.json`.
. Open both paths in the GUI and edit tokens, presets, or bindings.
. Export concrete artifacts only after diagnostics report no errors.

The source SVG remains the geometry authority. Studio changes semantic
bindings and palette data only.
